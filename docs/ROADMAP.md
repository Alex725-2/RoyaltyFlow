# Дорожная карта

1. **Основа.** Решение .NET 8, домен, генератор CSV, xUnit, минимальный API.
2. **Импорт и хранение.** Восемь таблиц PostgreSQL, каталог, версии договоров, потоковый CSV, идемпотентность, начисления в транзакции и базовый Dapper-отчёт. Следующая проверка этапа — запустить отдельные PostgreSQL 16 тесты и проверить планы на небольших представительных данных.
3. **Фоновая обработка.** После согласования добавить RabbitMQ и MassTransit, outbox, повторы и проверки восстановления после сбоев.
4. **Отчётность.** Расширить аналитические проекции и подготовить интерфейс React.
5. **Эксплуатация.** Добавить метрики, профилирование, контроль параллельных загрузок и измерения пропускной способности.
