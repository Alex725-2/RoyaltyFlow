# Домен

| Тип | Роль |
| --- | --- |
| Artist | Исполнитель |
| Track | Трек с идентификатором исполнителя |
| RightsHolder | Правообладатель |
| RoyaltyContract | Контракт для одного трека со снимком долей |
| RoyaltyShare | Доля одного правообладателя в процентах |
| UsageRecord | Событие использования с платформой, страной, датой и количеством прослушиваний |
| RoyaltyAccrual | Начисление по событию, контракту и правообладателю |

## Правила расчёта

1. Контракт требует положительных долей с точностью до четырёх знаков после запятой. Сумма строго равна 100%. У каждого правообладателя в рамках контракта непустой уникальный идентификатор. API принимает до 100 долей.
2. Событие должно относиться к треку контракта. Отрицательное количество прослушиваний отклоняется. Ноль даёт нулевое начисление каждому правообладателю.
3. Общая сумма равна количеству прослушиваний, умноженному на фиксированную ставку 0,015 денежной единицы. Сумма округляется до двух знаков через `MidpointRounding.AwayFromZero`.
4. Квота каждой доли вычисляется в копейках от округлённой суммы. Сначала выдаётся целая часть каждой квоты, затем оставшиеся копейки выдаются по одной в порядке убывания дробной части. При равенстве используется возрастание `Guid` правообладателя. Например, 3 копейки при долях 50/30/20 распределяются как 1/1/1.
5. Деньги и точные квоты считают через `decimal`, целые копейки хранят в `long`. Предел суммы составляет `92 233 720 368 547 758,07`. Превышение вызывает `OverflowException`. CSV принимает от 0 до 1 000 000 000 прослушиваний на событие.

## Версии договоров

В PostgreSQL одна версия договора покрывает интервал `[validFrom, validTo)` для трека. Пустое `validTo` означает открытый период. Трек представляет единственный набор прав на этапе 2. Модель Domain сохраняет снимок долей и не содержит правил выбора версии. Период находится в persistence-модели, а импорт сопоставляет его с датой события. Событие без подходящей версии сохраняется без начисления. Добавление договора впоследствии не запускает перерасчёт старых событий.

Используется одна расчётная валюта с двумя десятичными знаками. Региональные ставки и сторно остаются за пределами этапа.
