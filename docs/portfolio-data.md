# Демонстрационный каталог

Имена исполнителей и названия песен соответствуют опубликованным записям. Права, контракты, распределение долей, платформенная статистика и суммы роялти в RoyaltyFlow вымышлены. Каталог помечает треки и правообладателей как `[DEMO]`, события носят ту же метку в названии платформы, а Swagger и заголовок `X-RoyaltyFlow-Data` поясняют, что пометка распространяется на связанные договоры и аналитику.

Набор использует двух вымышленных правообладателей и один договор на трек с долями 60/40 или 70/30. Четыре комбинации платформ и стран дают 480 синтетических событий за каждый из шести завершённых месяцев UTC. Суммы рассчитывает штатный импорт RoyaltyFlow и сверяет seed на уровне каждого трека.

Чтобы после публикации заполнить базу, запустите из обычного Windows PowerShell:

```powershell
& 'E:\RoyaltyFlow\scripts\deploy-fornex.ps1' -SeedPortfolio
```

Заполнение начинается после health и read-only smoke. Оно использует операторский токен с VPS для записи через loopback и проверяет сохранённый каталог, события и начисления публичным API под демо-учётной записью. Повторный запуск в том же месяце использует прежние идентификаторы и квитанции. При смене месяца добавляется новый завершённый месяц. Данные закрытых периодов и существующий smoke-набор сохраняются. При несовпадении ранее записанных данных seed останавливается с ошибкой.
